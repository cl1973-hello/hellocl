    关于

    一个只用来看自己数据的小台子。

    本网站个人设计，仅供学习使用！

    把 CSV、Excel 或 JSON 文件拖进来，它会原样保存在你自己的浏览器里，并统计每个文件有多少条数据、占多少空间。 没有账号，没有服务器，也没有人在后台看你的数据 —— 因为这个站点压根没有后台。

    能做什么

    • 上传支持 .csv / .xlsx / .xls / .json，可多选、可拖拽，文件按原始字节保存，不做格式转换。
    • 统计自动识别每个文件的数据条数，表头不计入，再汇总成页面顶部的读数合计。
    • 预览在「数据表」里点开任意文件，看前 20 行内容，确认传对了没有。
    • 取回随时把上传的原文件下载回本地，和原文件逐字节一致。

    一些说明

    • 数据只存在这台设备的浏览器里，换设备、换浏览器都看不到。
    • 清除浏览器数据（或使用无痕窗口）会连同文件一起删除，无法找回。
    • 建议把重要文件在「数据表」里下载一份，别只留在这里。
    • Excel 支持 .xlsx 全量解析；旧版 .xls 能保存原文件，但无法统计行数，会显示为「—」。
